# Hotclock Stream Deck plugin

The Elgato Stream Deck plugin of Hotclock (M4). Author: Neglectware. Plugin id: **`com.neglectware.hotclock`**.

> **Deviation from architecture section 8, recorded 2026-10-07:** the design says `org.example.hotclock` ("a
> placeholder until the name is chosen"). Hotclock may be published under the Neglectware vendor name, so the plugin id,
> the author and every action id use `com.neglectware.hotclock`. No host name, address or person of any installation is
> in the plugin: the box address is a setting.

User documentation is the **Stream Deck plugin** page of the built-in Help (`crates/serve/help/stream-deck.md`).

## Layout

| Path | What |
|---|---|
| `src/core/` | everything that does not touch the Stream Deck SDK: the station model (`model.ts`), the reconnecting WebSocket (`link.ts`), the shared connections (`hub.ts`), the key painter and press tracker (`painter.ts`), the key controller (`controller.ts`), the SVG renderer (`svg.ts`) |
| `src/actions/` | one `ActionDef` per action: its face (state to picture), its press, its long press, its poll |
| `src/plugin.ts` | the SDK glue: registers one `SingletonAction` per `ActionDef`, global settings, wake, the property inspector's questions (`src/pi.ts`) |
| `com.neglectware.hotclock.sdPlugin/` | the plugin folder: `manifest.json` (generated by `tools/gen-manifest.ts`), `ui/` (one property inspector for every action), `imgs/`, `bin/plugin.js` (built, not committed) |
| `test/unit/` | Vitest unit tests (renderer, every action's face, link, hub with a fake box, the built plugin as a process against a fake Stream Deck app) |
| `test/integration/` | Vitest tests against real Hotclock processes, run by `dev/m4-deck-check.sh` |

## Commands

```
npm install
npm test                  # unit tests
npm run build             # rollup: bin/plugin.js
npx tsx tools/gen-manifest.ts   # after adding or renaming an action
npm run pack              # build, `streamdeck validate`, `streamdeck pack` -> dist/com.neglectware.hotclock.streamDeckPlugin
dev/linux-test.sh cargo build -p hotclock && dev/m4-deck-check.sh   # integration, from the repository root (needs Docker)
```

The SDK is `@elgato/streamdeck` 2.1.x (SDK version 2 manifest, Node 20 in the manifest). Stream Deck 6.9 or later.

## Adding an action

1. Write an `ActionDef` in `src/actions/` and add it to the list in `registry.ts`.
2. Add its name, tooltip and icon glyph to `META` in `tools/gen-manifest.ts` and run it.
3. If it has settings, add its fields to `SPECS` in `ui/pi.js`.
4. Add its row to the table in `crates/serve/help/stream-deck.md`, and a unit test of its face and press.
